# 📚 Sobre o Projeto

A **Biblioteca Virtual** é um sistema web desenvolvido como projeto escolar utilizando **Node.js**, **Express** e **EJS**.

Seu objetivo é facilitar o gerenciamento de livros através de uma interface simples, moderna e intuitiva, permitindo que novos livros sejam cadastrados e visualizados em forma de catálogo.

---

# ✨ Funcionalidades

✅ Página inicial com catálogo

✅ Cadastro de livros

✅ Informações do autor

✅ Sinopse

✅ Capa do livro

✅ Interface responsiva

✅ Layout moderno utilizando Bootstrap

# ⚙️ Como Executar

Clone o projeto

```bash
git clone https://github.com/seu-usuario/biblioteca.git
```

Entre na pasta

```bash
cd biblioteca
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm start
```

Abra no navegador

```
http://localhost:3000
```
